No account or sign-in is needed. On first launch, choose "Skip for now": the optional Banyan server is run privately by each organisation, so there is no demo server, and the app is complete without it.

To try it without a printer:
1. Desk: choose "New entity", enter a name and payee, and save.
2. Tray: write a cheque to it. The leaf preview shows where each field will print.
3. Choose "Record as handwritten", then "Record it". Printing is the only step that needs a printer.
4. Open Register to see the entry, and Year or Monthly for the reports. Open any row to see its payments and change a category or note.

Banyan prints only onto genuine bank-issued cheque leaves in the user's printer. It never draws a cheque, security artwork, a signature or a MICR line on blank paper.

Entitlements: printing, to send the page to the macOS print system at 100% scale; network client, for the optional server and to check the printer is on; Downloads, to save CSV and PDF exports.

The preview is drawn over a redacted photograph of the leaf the app was measured for (a State Bank of India multi-city cheque). Banyan is not affiliated with the bank and uses its leaf for nothing else.
